## 🚀 Key Platform Features

- **⚡ Live Dynamic Google Sheets Job Engine**: Automatically renders active job listings directly from Google Sheets (CSV) with real-time category filtering, recommendation badges, and priority sorting.
- **✉️ Web3Forms Submission Integration**: Secure backend contact submission on `contact-us.html` & candidate CV upload flow on `post-resume.html` with automatic redirect to `thank-you.html`.
- **🎯 Schema.org JSON-LD SEO Infrastructure**: Built-in Google Rich Snippet support (`EmploymentAgency`) targeting national search rankings for recruitment and software development keywords.
- **🔄 Animated 5-Step HR Hiring Pipeline**: Interactive node-based diagram showing end-to-end talent sourcing, screening, background verification, and onboarding.
- **💻 Animated 5-Step IT Software SDLC Pipeline**: Interactive lifecycle visualization from architecture discovery to CI/CD cloud deployment.
- **🎨 Glassmorphism & Modern UI System**: Built with modern CSS custom variables, vibrant dark modes, subtle micro-animations, and responsive cards.

## 📊 Live Google Sheets Job Setup

To connect a live Google Sheet to update jobs dynamically:
1. Follow the exact column schema in [`GOOGLE_SHEETS_JOB_SETUP.md`](GOOGLE_SHEETS_JOB_SETUP.md).
2. Publish Google Sheet as **Comma-Separated Values (.csv)**.
3. Pass your CSV URL to `window.GOOGLE_SHEETS_CSV_URL` in `index.html`.
